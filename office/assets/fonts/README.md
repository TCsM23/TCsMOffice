Fonts bundled with TCsOffice, all under the SIL Open Font License 1.1
(see the OFL-*.txt files next to them):

- Alegreya SC (regular and bold): titles, headings, buttons and labels
- EB Garamond (roman and italic): body text, cells and menus
- Grenze Gotisch: the blackletter wordmark and display titles

They're loaded at startup with QFontDatabase, so nothing needs installing to
run the app. Install them on your system too if you want Word or PowerPoint
to show saved files in the same fonts.
